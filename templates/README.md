# Reusable workflow templates

These templates originate from dev-to-prod-workflow commit
`70652f67cbc61a2d76d8a2ba9284d6e6b8b42279`. The files retain their source content
with trailing whitespace normalized.

- [Current activity plan](PLAN.current-activity.md): copy to local `PLAN.md`.
- [Adoption preflight](template-adoption-preflight.local.md): complete a local
  copy when adapting the workflow.
- [Readiness issue ledger](production-readiness-issues.local.md): use a local
  copy when a review needs multiple issue dispositions.

Blank fields and prompts are intentional in these reusable source files.
Completed project records remain local and ignored. These templates are
development aids and are excluded from the runnable demo deployment package.
